# Gold Rush — тапалка для Telegram

Mini App с 3D-монетой: тапы, энергия, карточки пассивного дохода, ранги, рейтинг, друзья, задания, магазин за Telegram Stars и админ-панель.

Монеты игровые. Их нельзя вывести, и выплат за приглашения нет.

## Что внутри

**Игра** (`public/`):
- 3D-монета на Three.js. Наклоняется к пальцу и раскручивается от быстрых тапов. Если WebGL недоступен, показывается обычная монета.
- 7 карточек пассивного дохода. Каждая следующая открывается после прокачки предыдущей, рядом показано, за сколько окупится.
- Бусты: мультитап, запас энергии, скорость восстановления.
- 6 рангов, рейтинг лучших игроков и скины монеты.
- Ежедневная награда с серией до 7 дней, задания, друзья с бонусами.
- Офлайн-доход до 3 часов с окном «Пока тебя не было…».
- Обучение для новичков.

**Магазин за Telegram Stars:**
- Полная энергия, турбо ×2 на час, пакеты монет, VIP на 30 дней, платные скины.
- Защита от подмены: цена и покупатель проверяются в `pre_checkout_query`, повторное уведомление не начислит покупку дважды.
- Команды `/paysupport` и `/terms`, которые Telegram требует для приёма оплаты.

**Админка** (`/admin`):
- Обзор: игроки, активность, звёзды, графики за 14 дней, самые продаваемые товары.
- Игроки: поиск, карточка игрока, изменение баланса, бан.
- Задания: подписка на канал (бот сам проверяет подписку), переход по ссылке, приглашение друзей. Всё меняется без перезапуска.
- Платежи: список и возврат звёзд в один клик. Покупка при этом отменяется.
- Рассылки: предпросмотр, тест себе, отправка всем с прогрессом и кнопкой «Остановить».

**Автоматизация:**
- Напоминания в боте: «энергия восстановилась, доход накопился». Не чаще раза в сутки, игрок может их выключить.
- Уведомление другу, когда по его ссылке кто-то пришёл.
- Админам приходят сообщения о каждой покупке. Команда `/stats` показывает сводку.
- Бэкап базы раз в сутки, хранятся последние 7.
- Кнопка меню и команды бота настраиваются сами при запуске.
- Автодеплой: push в GitHub → сервер обновляется сам.

## Запуск на сервере

Нужен VPS (Ubuntu, от 1 ГБ RAM) и домен, направленный на IP сервера (A-запись).

1. **Создай бота.** Напиши @BotFather команду `/newbot` и сохрани токен.
2. **Подготовь сервер.** Зайди по SSH и выполни:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/<аккаунт>/<репозиторий>/main/deploy/setup.sh -o setup.sh
   bash setup.sh https://github.com/<аккаунт>/<репозиторий>.git
   ```
   Для приватного репозитория клонируй его вручную в `~/tapalka` (с токеном или deploy-ключом), а потом запусти `bash ~/tapalka/deploy/setup.sh x`.
3. **Заполни настройки.** Открой `nano ~/tapalka/.env` и впиши `BOT_TOKEN`, `DOMAIN`, `WEBAPP_URL`, `ADMIN_PASSWORD`, `ADMIN_IDS`.
4. **Запусти.** Снова выполни `bash ~/tapalka/deploy/setup.sh x`. HTTPS-сертификат Caddy получит сам.
5. **Зарегистрируй Mini App** (рекомендуется). В BotFather: `/newapp` → выбери бота → укажи URL игры. Короткое имя впиши в `APP_SHORT_NAME`, затем выполни `docker compose up -d`.

### Автодеплой

В GitHub открой репозиторий → Settings → Secrets and variables → Actions и добавь три секрета:
- `SSH_HOST` — IP сервера,
- `SSH_USER` — пользователь,
- `SSH_KEY` — приватный SSH-ключ.

После этого каждый push в `main` сам обновляет игру.

### Полезные команды на сервере

```bash
cd ~/tapalka
docker compose logs -f app       # логи
docker compose restart app       # перезапуск
docker compose up -d --build     # обновить вручную
```

Бэкапы лежат в томе `game-data`, в папке `backups/`.

## Локально, без Telegram

```bash
cp .env.example .env     # поставь DEV_MODE=1, ADMIN_PASSWORD=любой
npm install && npm start
```

- Игра: `http://localhost:3000/?dev=1`. Число — ID тестового игрока, `&ref=ref_1` проверяет рефералку.
- Админка: `http://localhost:3000/admin`.
- Оплата звёздами работает только внутри Telegram.

## Настройка экономики

Все цифры лежат в `server/config.js`:

- `GAME` — энергия, бонусы за друзей, ежедневные награды.
- `UPGRADES` и `CARDS` — цены, рост цены и доход. Через `requires` задаётся, после какой карточки открывается следующая.
- `RANKS` — ранги.
- `SKINS` и `PRODUCTS` — скины и товары за звёзды.

Название игры и буква на монете берутся из тега `<title>` в `public/index.html`. Цвета задаются в начале того же файла.

## Безопасность

- Каждый запрос проверяется по подписи Telegram, баланс считает только сервер, тапы ограничены 15 в секунду.
- В админку пускает только пароль. Подбор ограничен 5 попытками в минуту.
- На сервере всегда держи `DEV_MODE=0`.
